## 一、交付清单（四段）

### ① 出卷流水线转正（核心）

把战役 scratchpad 四件套沉淀为正式件（源件在 scratchpad，逻辑以 迁移记录 窗G 条为准）：

| 临时件 | 转正落点 | 要点 |
|---|---|---|
| 选题器 v4 | `工具箱/组卷/draft_paper.py`（新建） | 配方 JSON 驱动；五维取题（单元×题型×难度×考点×版本使用级）；全局互不重题；降档替补留痕；产出方案 JSON |
| 构建答案包/dump物料 | `工具箱/回流/answer_batch.py`（新建） | 无答案清单→分批物料→（解题工作流由 skill 提示词承载）→答案包构建+覆盖率对账 |
| 浙教出件/验PDF | 并入 `工具箱/组卷/paper_tool.py` 或独立 `工具箱/组卷/paper_run.py` | 方案 JSON→assemble(按名幂等)→render-pack(相对路径)→双PDF→机器验页（页数/题号连号/零待补答案） |
| 命题明细 | 随 draft_paper.py 一并产出 | 逐题 单元/考点/难度/使用级/来源+替补清单 |

**新 skill：`出卷流水线`**（.claude/skills/）——配方→选题→补答案（双盲+裁判工作流模板提示词）
→出件→明细 全流程编排；铁律（单写者/写窗口登记/闸不放宽/模型口径 opus·sonnet 分层）写死。

### ② 闸补缺（四处，每处配反例用例）

1. **asset 域正式写入门**：ingest_flow 或独立工具加 `asset-add`（hash 复算/rel_path 相对根/幂等），
   替代窗内显式 SQL；
2. **figure 悬空指针机器闸**（X7）：gates 或 ingest 校验 figure.asset 在 asset 表且文件在盘；
3. **泄答案闸白名单口径**：题面固有「解：/答：」（阅读理解类/作答提示位）不误拦——口径=只拦
   渲染器注入的答案元素（ansv/着色/ansline），不拦题面 md 原文；改闸必配正反例（战役实拦 2 例为反例素材）；
4. **试卷处理管线 skill 契约修正**：补「结构化件 rows 需 cells 包层」条。

### ③ 账面清整

- 孤儿 artifact 清理（首跑 render-pack 失败所建 6+ 行，含旧命名复刻卷）：定清理口径（退役标记，不物理删）；
- 图审工单 29 张人审流（console 或 CLI 逐单过）＋ promote 上架流首跑（现全库草稿态）；
- 旧 3 平行卷 artifact 定稿（题已归池，卷 PDF 移退役）；
- 记录/发布物料正本.md §2 教材归属表补本批。

### ④ 发布链适配"卷"类产物

发布包/合成封面/AB隔离 三脚本现为打卡册专用（`产物\打卡\` 路径耦合、Day 线取图）——
