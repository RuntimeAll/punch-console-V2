## 1. 铁律（每条都是闸，不是注释）

- 🔴 **零 LLM 优先**：B 段（规则切割）必须先把能机械吃的全吃完，剩下的才准进 C 段（公式重排）。
  凡"这题用模型顺手改一下"= 越界；规则能覆盖的一律回去改规则。
- 🔴 **切割器不写库**：切割器的出口只有一个 —— 符合 `ingest_flow` 题目包格式的 JSON 文件。
  入库动作单独一步、单独在主位执行、单独记账。切割器里出现任何 `kb.db` 写连接 = 拒收。
- 🔴 **靠闸不靠注释**（CLAUDE.md §3）：守恒闸（字符多重集/图/表）、剥离账逐题平衡、REGEXP=0、
  无误剥、考点叶子闸、公式可解析闸 —— 违例**拒收不静默**，不许为了数字好看放行。
- 🔴 **不确定一律落人审**：判不准的题标低置信 + 落人审清单，绝不静默入库、绝不静默丢弃。
- 🔴 **id 全链路字符串；文件指针全相对路径**（老货架 717 行绝对路径全断）。
- 🔴 **一标记一题，小问不拆**（CLAUDE.md §3 / 数据结构定稿）；分值与题号不进 question 表，走抽离账。
- 🔴 **老区 `D:\workplace\ai-bkb` 只读**：参考件只读、原料只拷不引用；不调备课帮 prod 任何服务。
- 🔴 **开发位 = `D:\workplace\ai-bkb-v2\codeplace\`**（用户 2026-08-19 定名），worktree 开在这下面。
  worktree 里**绝不碰主位的两库**；动库要沙盘就在自己位里开**副本库**；主位入库是显式单独一步。
- 🔴 **公共契约件只在主位改，要动先到调度中心排队**：`认知\数据结构.md`、DDL、`工具箱\库\gates.py`、
  `工具箱\回流\ingest_flow.py`、console 的 mock/types、`criterion` / `ingest_template` 判据表。
  本卡**独占**的只有 `工具箱\切割\` 与本卡目录。
- 🔴 **不合回 master 不算完结**（完结判据含"已合并 + 已收位"）。
- 🔴 py 脚本开头 `sys.stdout.reconfigure(encoding='utf-8')`；PowerShell 复杂命令落脚本再跑。
- 🔴 **预算红停**：C 段实耗 token 逐批记账，超本卡估算口径 2 倍立即停手报调度中心，不硬闯。
