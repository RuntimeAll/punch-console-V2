## 1. 铁律（每条都是闸，不是注释）

- 🔴 **老区零变更**：`D:\workplace\ai-bkb\订阅特训\` 只读——库一律 `mode=ro` uri 打开，文件**只拷出不引用**；
  脚本里写死老区路径守卫（老区路径只允许出现在"源"参数位，出现在写通路即拒跑）。
- 🔴 **自包含可迁云是硬判据不是口号**（D-5）：`批改产线\` 整目录拷到任意临时路径**仍能跑**——
  不 import kb.db、不连 :4300/:4310、不出现主位绝对路径。阶段5 有机器闸真验。
- 🔴 **grading.db 内不出现 kb 外键**：考点集/题单只以**快照**形式携带（`kp_scope_json` / `题单快照/<track_id>/D<day>.json`）；
  学情回流**单向只读**，kb 永不被本卡写一个字节。
- 🔴 **九态是唯一迁移图**：`收件中/待认卷/待人工认卷/批改中/待终审/已确认/待出件/已出件/故障`——
  白名单 + 合法迁移表，**非法迁移拒写不静默**；每次迁移必写 `state_since`；故障**就地挂起不自动重试**。
- 🔴 **零 LLM 机械批处理优先**（§3 数据纪律）：学员平移、老批次归轨、状态机流转、学情现算——**全是机械脚本**；
  LLM 只出现在"判卷/写总结"两段（本来就是认知活）。归轨绝不逐条 AI 猜。
- 🔴 **学情没有表**（D-2）：按轨现算，分母=`track.kp_scope_json`；跨轨只并列不加总；
  唯一落盘=出件那一刻的 `batch.xq_snapshot_json`。**本卡出现任何"学情汇总表"DDL 即违规**。
- 🔴 **id 边界纪律**：库内主键照 DDL（track/batch 为 INTEGER 自增，不改结构）；但**一切出库的 id**
  （JSON 快照/文件名/回执/日志/端点参数）一律**字符串**（雪花 double 截尾教训）；跨库软引用 `kp.id` 本就是 TEXT。
- 🔴 **文件指针全相对路径**：`photos_json`/`task_ref`/`report_file`/学员目录 一律相对 `批改产线\`（老货架 717 行绝对路径全断）。
- 🔴 **不确定一律落人审不猜**：认卷零命中/多命中→`待人工认卷`；考点挂不上→标低置信进人审清单（叶子闸口径：绝不静默挂章级）。
- 🔴 **术语禁"台账"**（用 记录/清单/待办/队列）；py 脚本开头 `sys.stdout.reconfigure(encoding='utf-8')`；
  PowerShell 复杂命令落脚本再跑。
- 🔴 开发位=`D:\workplace\ai-bkb-v2\codeplace\wt-prd005`（worktree），主位两库**绝不碰**；
  动库结构在自己位里用**副本库沙盘**，DDL 定稿后回主位一次显式执行（见 §2 排队规则）。
