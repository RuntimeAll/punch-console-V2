# 答案实算闸 —— 交付前的机器判卷

**什么时候必跑**：自编题（DSL/参数化）全量、变式题全量、**交解析卷必加跑逐行恒等**。
「看着对」不算过闸；闸不绿就修参数重出，🔴 **绝不手改答案凑数**。

## 1. 自编题六查（活样板 = `工具箱/dsl/有理数混合运算_qbank.py` 的 `verify()`）

| # | 查什么 | 判据 / 机器怎么查 |
|---|---|---|
| ① | **逐题机器实算** | 题面**独立路径**求值 = 声称答案：从题面字符（LaTeX）重新解析成 sympy 精确值，不走生成时的表达式树。🔴 `rational=True`——浮点残差会把 `6.8-11.8+12.2-7.2` 算出 `1e-27` |
| ② | **解集唯一** | 方程/不等式解集唯一且非空；分类讨论题每个分支都要落地，不许「另一解静默丢」 |
| ③ | **册内查重** | 题面归一化后**全册零重复**（faces 集合跨天累积）。🔴 只在本册内查，**跨册撞题不拦不报警**（2026-08-17 用户拍板，别为它写闸） |
| ④ | **范围闸** | 超纲运算不出（该学段没学的运算/符号一律不进题面）；值域·分母·步数对表（样板：\|答案\|≤200、分母≤36、过程行数≥2） |
| ⑤ | **题面纯净** | 题面只有题：禁指令词（「请用简便方法」「参照上题」这类编排话术）、禁答案泄漏、禁跨题引用 |
| ⑥ | **难度梯度对表** | 每题难度与大纲/日程表申报的档位一致（逐日加码还是平行按册规格），错档=编排事故 |

`verify()` 返回 False = 不过闸，一题红就整卷不出。新写 DSL 照这份 `verify()` 的骨架抄，不要另起一套。

## 2. 逐行恒等校验（`工具箱/验算/逐行恒等校验.py`）

**口径**：只验最终答案挡不住「**中间行符号错、末行锚回正确答案**」——
2026-07-30 有理数打卡第二天第 9 题实锤：去括号漏变号，末行又锚定回已验算的正确答案，
答案验证闸对这种错误完全免疫。**交解析卷必跑**。

```powershell
python 工具箱/验算/逐行恒等校验.py cases.json    # 逐题 PASS/FAIL + 汇总；有 FAIL 退出码 1
```

输入 JSON（转写层产出，通常由多模态 subagent 对照卷面逐行转写）：

```json
[
  {"id": "第2天-9", "mode": "expr",
   "lines": ["-2**3-(-3+(-3)**2/(-S(1)/6))", "-2**3+3+(-3)**2/(-S(1)/6)"],
   "answer": "49"},
  {"id": "专项一-1", "mode": "eq",
   "lines": ["4-3*x=6-5*x", "-3*x+5*x=6-4", "2*x=2", "x=1"],
   "answer": "x=1"}
]
```

- **第 1 行 = 原式（照抄题目）**，后续行 = 解析每一步；`answer` = 卷面标注的最终答案。
- `mode`：`expr`=表达式链（每行精确求值必须等于第 1 行，answer 也相等）／
  `eq`=方程变形链（每行解集必须与第 1 行方程一致，answer 形如 `x=值`）。
- **转写规范**：`÷`→`/`　`×`→`*`　乘方→`**`　分数→`S(a)/b`（保精确有理算术）　`|x|`→`Abs(x)`　
  带分数 `8½`→`(8+S(1)/2)`。🔴 转写必须**忠实卷面**，不许顺手改错——改了等于闸自己瞎了。
- 不可机读行（省略号数列等）加 `SKIP:` 前缀：跳过该行、其余照验；**首行 SKIP = 整题只能人工抽查**。
- parse 失败 / 无解方程 → FAIL 附原因，**绝不静默跳过**。

## 3. 三条铁律

1. **答案不撞**：每题最终答案与**母题答案 / 题目已知量 / 兄弟变式答案**全不同——
   撞了学生一眼看穿是换皮题。这是纯语义闸，sympy 不会提醒你，靠人/靠编排脚本自己列表比对。
2. **验算与题面同源**：验算数据与卷面题面出自**同一组参数**（一次生成同时吐题面+答案+过程），
   杜绝「题面一套、答案另录一套」的**双录漂移**——两边各自都对、合起来错，是最难查的一类事故。
3. **走独立第二条路**：验算**绝不复用**生成解析时的中间步骤/表达式树——
   从题面字符重新解析求值才叫验算；复用 = 自己给自己判卷，等于没闸。

## 4. 收尾落账

```powershell
python 工具箱/库/log_skill.py 答案实算闸 <动作> <成功|失败> "<要点>"
# 例：python 工具箱/库/log_skill.py 答案实算闸 全册实算 成功 "浙教七上有理数30天600题 verify 全绿 + 逐行恒等 0 FAIL"
# 例：python 工具箱/库/log_skill.py 答案实算闸 逐行恒等 失败 "第2天-9 第3行去括号漏变号，退回改解析"
```

失败**也要记**（FAIL 数 + 代表性错项），事故复现与判据沉淀都靠它。
