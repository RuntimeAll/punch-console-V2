## 2. 目标与非目标

**目标**：
1. 教辅整书的**版式档案**（结构长什么样，机器怎么认）；
2. 试切**一个单元**的完整产物：题目卡（块流）+ **归属树**（题→考点→栏目→单元；这个系列的书就是
   按考点组织的，文件名都标着【N大考点】，切出来的题应能**自动预挂考点名**）+ **例题↔练习配对**；
3. 🔴 **抽离准确性**（用户点名）：题号/分值/来源标记/栏目前缀从题面**剥离带账**（照契约层考古 §7 的
   老区规格：REGEXP=0 口径前移成代码闸、`(?!\d)` 前瞻防 1.5 被剥成 5、可见字符多重集守恒）；
4. 🔴 **导出准确性**（用户点名）：从块流**渲染回打印件**（HTML→PDF，原卷版式：题目卷不带答案），
   与原件逐题人工比对——验证"存进去的能原样拿出来"（存取同构的实战检验）；
5. 验收数（§7）；沉淀：**系列通用的录入模板规则**（不只这一本——后面整个系列都要录）+ 新判据。

**非目标**（越界=跑偏）：
- ❌ 不入库、不建库、不动 `数据结构.md` 与 console/；
- ❌ 不切全书（只切一个单元，够验证就行）；
- ❌ 不调 LLM API（本轮仍验证**确定性层**的成色；哪里确实需要 LLM 辅助，写进报告作为分层建议，不现场用）；
- ❌ 不做 OCR/图片链（只吃 docx 文字层）。

## 4. 方案（四步，用户已确认）

| 步 | 干什么 | 产出 |
|---|---|---|
| ① 探版式 | 先不切题。机器扫全书：标题层级（哪级样式=单元/小节）、栏目标记（考点讲解/典例/变式练习/巩固…的识别特征）、编号体系（题号在栏目内重启？全书连续？）、图表/公式分布、是否多栏 | `版式档案.md`（+机读 `版式档案.json`） |
| ② 模板判定 | 对照老区方言经验（见 §5 资产），归纳**这本书的切割模板规则**：栏目边界怎么认、题目边界怎么认、讲解与题目怎么分流、例题↔练习怎么配对 | `模板规则.md`（将来 ingest_template 的第一条真数据） |
| ③ 试切一个单元 | 切：题目卡（块流）+ 归属树（预挂考点名）+ 例题练习配对 + **题干元信息抽离**（题号/栏目前缀/来源剥离带账，守恒断言）；守恒闸照旧（图数/公式数/字符多重集） | `切割结果.json` + `预览.html`（左=原文连续预览，右=归属树+题目卡+抽离账） |
| ④ 导出还原 | 从块流渲染回**打印件**（HTML→Chrome→PDF，题目卷不带答案），与原件（可对照同目录 PDF）逐题人工比对：字符/公式/图/版式可用性 | `导出-题目卷.pdf` + 比对记录 |
| ⑤ 验收 | 人工抽查底稿 + 五个数 + 需人审比例；诚实写"哪类版式会切错、什么必须上 LLM、什么纯规则就够" | `切割报告.md` + `预览截图.png` |

## 7. 验收标准（调度中心终验按此收）

1. 五件产物齐：版式档案 / 模板规则 / 预览（截图已自检）/ **导出题目卷 PDF** / 切割报告；
2. **五个数** + 需人审比例，且有**人工抽查底稿**（抽 ≥15 题逐题核对原文，附对照记录）：
   ① 题目边界切对率 ② 归属（考点预挂）正确率 ③ 例题练习配对率
   ④ **元信息抽离准确率**（剥离账平衡、REGEXP=0、无误剥实例）⑤ **导出保真率**（逐题比对无损/降级清单）；
