## `_卷面生成工具/`（18 个，源自「苏俊宇-暑期课」）

- `crop_u6.py`：从原书 PDF 按坐标裁出第六单元「条形统计图」最后 4 题的图（图表密集重排必失真，直接裁原书版面最忠实）。
- `cube3d.py`：观察物体图形渲染器——等距立方体堆 + 三视图方格图生成器。
- `fetch_u5.py`：直连线上教务 BE（www.jpjia.cn/api）拉取四上第五单元 18 考点 102 题的完整数据+题图，产出 `u5_questions.json` + `figs/`。
- `gen_l10.py`：第10课「平行四边形（钉板课）」卷面生成器（思维题钉板四关 + 同步奥数11题）。
- `gen_l11.py`：第11课「平行四边形和梯形 × 条形统计图」卷面生成器（思维·梯形阵 + 同步16题 + 统计图4题）。
- `gen_l1_l2_补档.py`：第1/2课档案补齐生成器（L1=最值专项重构版，L2=三段全量重排）。
- `gen_l5.py`：第5课「等差数列巧算」题目卷+答案卷生成器（专项12+课内10+思维三关挑战卡）。
- `gen_l6.py`：第6课「周期问题」题目卷+答案卷生成器（思维·生肖三关+专项10+同步应用专场10）。
- `gen_l7.py`：第7课「行程问题」题目卷+答案卷生成器（思维·小狗折返跑三关+专项12+同步过关8）。
- `gen_l8.py`：七月小测·综合测试卷 v2 生成器（40分钟100分22题，正规试卷版式+竖式数字谜化）。
- `gen_l9.py`：第9课「观察物体」出图+题目卷/答案卷生成器（魔方涂色三关+观察物体专项10+1+平四梯形同步10）。
- `gen_zhuanxiang_pstx.py`：《平行四边形和梯形·专项》题目卷+答案卷生成器（第五单元18考点102题，五大板块认知台阶重排）。
- `gen_等差三关.py`：等差数列巧算·三关思维题生成器（学生挑战卡+教师引导卷，第5课思维题部分）。
- `gen_钉子板探究.py`：钉子板五关探究生成器（皮筋围正方形，学生挑战卡+教师引导卷）。
- `gen_课时卷模板.py`：苏俊宇课时卷生成模板（定版工艺，2026-07-14）——复制改名、填题目数据即可出新课次卷。
- `gen_同步课.py`：平四梯形一轮·同步课卷通用生成器（由 `gen_l10.py` 泛化定版，命令行传课次名一条命令出双卷 HTML）。
- `paper_css.py`：卷面版式定版 CSS，所有生成器统一 import（三条硬规矩：不许大规模涂色/标题不写题数/悬挂缩进对齐）。
- `pegboard.py`：钉板（geoboard）渲染器，配合实物钉板教具出卷面图。
- `u5_pick.py`：同步段题源模块（四上第五单元 平行四边形和梯形），供课次生成器 import，含按板块挑题、渲染 HTML、避重断言三件事。

## `_验算/`（11 个，源自「苏俊宇-暑期课」）

- `extract_u5.py`：从原书 PDF 抽取第五单元（p99-119）题目卷 + 对应答案解析卷。
- `geoboard.py`：钉板平行四边形计数全枚举验算（思维题三关口径校核，对角线互相平分法）。
- `geoboard2.py`：钉板计数细目验算（3×3 按对角线交点分类明细账；4×4 长方形/正方形明细）。
- `l10_verify.py`：第10课·同步奥数10题逐题实算校核。
- `l11_siwei_verify.py`：第11课思维题（小棒摆梯形阵 × 等差数列）验算，三关逐根累加校核（不只套公式）。
- `l11_verify.py`：第11课「找正方形」× 平行四边形计数题全枚举/公式双算校核。
- `l9_design3.py`：第9课·观察物体10题数据定稿 v2 + 全量枚举验算。
- `l9_siwei_verify.py`：第9课思维题（小正方体教具·露在外面的面数）验算，公式 S=6n-2c 校核。
- `occl.py`：等距图遮挡自检——检测立方体堆图中被完全遮挡的「摞顶」（图不可用的硬伤检测）。
- `skewboard.py`：3×3 钉板整体推斜成平行四边形阵后，平行四边形/正方形计数是否仍守恒的验算（斜阵有理数精确枚举）。
- `tilt_rects.py`：列出 4×4 格点里所有「斜的」长方形（含斜正方形），供答案卷出图用。
