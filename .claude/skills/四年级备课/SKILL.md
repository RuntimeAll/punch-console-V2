`show` 会把该课次逐字段打出来，并把老区那张「字段→决定什么→教训」核对表原样印一遍。逐项对齐：

| 字段 | 决定什么 | 教训 |
|---|---|---|
| `主题` | **专项/奥数主题**＝教学意图。「吃透课」标记=旧题型二刷，靶心在思维动作，不是撒大网 | 第7课=吃透课①·两次相遇，相遇板块压后重讲 |
| `思维动作` | 这节课要练的那个动作（如"盯路程和"），选题围它转 | 撒大网=一节课什么都没吃透 |
| `课内进度线` | 🔴 **同步练习的主题，独立于专项主题**（老区实跑线：L5 多位数乘两位数·计算 → L6 应用 → L7 平四梯形 → L9/10 除法 → L11 统计图 → L12 广角收尾） | 2026-07-26：第7课专项是行程，同步也配成行程，被用户点破"你有看我的课程计划吗"。同步跟专项撞主题=课内进度断档 |
| `日期` | 第 N 课是哪一天，一律以计划为准，绝不按"数场次""内容像什么"自行推断 | 排期变动=用户拍板，别擅动 |
| `料源` | 专项料源（学而思第N周 / 讲义 / 用户拍页 / kb.db 考点枝） | 用户当场给料以用户为准，但把偏离写回本表 |
| `考点锚` | kb.db 的 `kp.id`（逗号分隔）＝取题与学情的分母 | 没锚点=学情算不出来 |
| `卷` | 已绑的卷（artifact id / paper 指针 / PDF 相对路径），别覆盖丢信息 | 改题=建新卷，旧卷留档不删 |

## 1. 课堂范式（90 分钟，2026-07-24 定版）

**思维题 10ʹ → 奥数专项 40ʹ → 课内同步 30ʹ → 总结 10ʹ**。一课一份合并卷：题目卷（学生）+ 答案卷（教师）成对。

60 分钟课=专项砍到 25ʹ、同步 20ʹ；45 分钟课=只留思维 5ʹ+专项 25ʹ+同步 15ʹ。

## 2. 三段选题规矩（教学法正本，一条都不许丢）

- **思维题**（1 道三关递进）：巧 > 难，"算得快不如算得巧"；三关=热身→巧法冲击→逆向/升级压轴；
  贴时事或当下情境（台风/马年/真实日历）；**题目卷不留任何提示，泄底的关名也算提示**
  （"往回数"这种关名=把坑告诉他）；坑和巧法全写进答案卷解析。
- **奥数专项**（40ʹ，10-13 题）：源=学而思36周书或用户拍页，**忠实转录**；已授权删减：
  重复题型、过易题、烂数字题（🔴 **每题先独立解一遍验整除性**——市面资料大量除不尽/题面自相矛盾，
  修题要换整数值并在 `prov.source_raw` 注明修改）；组织成【板块】方法卡：按题型分块、块内 ★ 爬坡到压轴；
  **方法口诀只进答案卷的板块头**，题目卷板块头只留知识点名。
- 🔴 **逐行恒等校验**（2026-07-30 增设）：自编/改编题若配了解析步骤链，交付前每个「＝」行都要与原式恒等
  （方程=每步同解）：
  ```powershell
  python 工具箱/验算/逐行恒等校验.py <解析文件或题目包>
  ```
  只验最终答案挡不住「中间行符号错、末行锚回正确答案」的 LLM 解析错误（有理数打卡 200 题抓出 5 道全是这形态）。
  全套六查走「答案实算闸」skill。
- **课内同步**（30ʹ，8-10 题）：主题=计划的**课内进度线**（见 §0），源见 §3；
  收尾过关口味=优先纯文字题，避开近期课已用过的题（剔重见 §3.3）。

## 2b. 测试课（小测/结业测）组卷规矩（2026-07-27 两轮纠正后定版）

🔴 **以举一反三专项为核心（约 7 成分值），课内同步为辅（约 3 成）**——别搞反，也别只考同步
（两个方向都错过一次）。题源全取**已上课次的题池**（v2 = `find_questions.py --in-artifact <往期卷>`
或按考点锚取）。题型骨架=填空＋选择（原题改编配选项另录入）＋计算＋数字谜（**必竖式形态**，
加减/汉字谜用 `gen_课时卷模板.py` 的 `vs()` □方格竖式表格）＋应用压轴。
测试卷版式与课时卷不同：正规卷头（题次/得分表格）、黑白打印友好（黑色大题标题+底横线）、
大题带一二三编号与分值、留作答空间、无★无提示。
🔴 **组卷前先出结构清单给用户过审再动手**（这是流程固有闸，不算"停下等人"违例）。

### 3.2 库里取题的命令（题层放量后即可用，现在跑=如实 0 行）

```powershell
# 按考点名/别名取（resolve 不中会报错，不会静默放宽）
python 工具箱/检索/find_questions.py --kp 平行四边形的认识 --difficulty 巩固 --unused --limit 10
# 🔴 纯数字 kp = id 前缀取整枝：400006 = 第六单元「平行四边形和梯形」整枝
python 工具箱/检索/find_questions.py --kp 400006 --qtype 应用题 --limit 20
# 剔重：本课不要出现往期卷用过的题
python 工具箱/检索/find_questions.py --kp 400006 --not-in-artifact <往期册id> --limit 12
python 工具箱/检索/find_questions.py --kp 400006 --like "梯形周长反求" --topk 8   # 语意排序（先过滤再排序）
python 工具箱/检索/find_questions.py --in-artifact <往期册id> --ids-only          # 已用题清单
```
组合条件一律 AND；考点/题型/难度多值 OR，标签多值 AND。查不到就是查不到，**别放宽条件蒙一批交上去**。

### 3.3 剔重（老区血案的 v2 做法）

老区靠人肉记"第7课卷184 已用 考点一×2、七×1、十四×3…"。v2 改用机器：
`--not-in-artifact <往期册id>`（组卷 take 也支持同键），以及 `--unused`（没进过任何卷）。
🔴 **计划的「卷」列就是往期册指针**——所以那一列必须认真填，它是剔重的入口。

### 3.4 题入库（老区 `ingest_items`+六闸 → v2 `ingest_flow.py` 三闸+执行阀+等级审）

```powershell
python 工具箱/kg/kg_tool.py resolve "平行四边形的高"          # ① 先把考点 resolve 通，resolve 不到先 add-leaf/alias
python 工具箱/回流/ingest_flow.py check  题目包.json           # ② 干跑：块流闸+执行阀五条+叶子闸+等级预判
python 工具箱/回流/ingest_flow.py ingest 题目包.json           # ③ 真入库（草稿）🔴 先登记写窗口
python 工具箱/回流/ingest_flow.py promote --ids q…,q…          # ④ 草稿→上架（过 assert_promotable）
```
- 🔴 **绝不裸题开工**：考点 resolve 不通先补 KG（「KG维护」skill）；
- 题面 blocks 只放**题目本体**：题号/分值/「计算：」类指令词一律不进题面（版式的事，闸会拦）；
- `prov` 带 `source_raw`（书名+页码/周次）与修改说明；扫描件 `source_kind='scan'` 自动 +1 等级审；
- L2/L3 自动开 `review_ticket`，**工单没处理完题上不了架**——照单人审，别 `--skip-review` 蒙混。

### 4A. gen 脚本路（复制改数据）
```powershell
copy 工具箱\备课\_卷面生成工具\gen_课时卷模板.py 备课\<学生目录>\第N课-<主题>-<YYYYMMDD>\gen_lN.py
# 改 LESSON / DATE / 🔴 OUT / 三段题目数据，然后：
python 备课\<学生目录>\第N课-…\gen_lN.py               # 出 HTML
```

🔴🔴 **平移件两个红线坑（2026-08-22 实测，跑之前必看）**：

1. **`工具箱/备课/_卷面生成工具/` 里所有 `gen_*.py` 的 `OUT` 仍指老区绝对路径**
   （`D:\workplace\ai-bkb\备课产物\…`）。**照抄直跑 = 往只读的老区写文件 = 违红线**。
   复制成课次脚本后**第一件事就是改 `OUT`**：
   ```python
   from pathlib import Path
   ROOT = Path(__file__).resolve().parents[N]        # 指到 v2 根
   OUT = str(ROOT / '备课/<学生目录>/第N课-<主题>-<YYYYMMDD>')   # 🔴 相对根拼，别写死盘符
   ```
   `crop_u6.py` 的 `SRC`、`gen_l1_l2_补档.py` 的 `ROOT` 同理。
2. 🔴🔴 **`_卷面生成工具/fetch_u5.py` 一律禁跑**：它直连备课帮 prod
   （`www.jpjia.cn/api` + 读 `book-ai\password\teacher-mcp-prod.env`），
   **正面违反 v2 独立生态零交互第一原则**。它只是历史留档，说明当年那批题怎么来的。
   要那份题源 = 从老区**只读拷**已生成的 `u5_questions.json`/`figs/` 进 `测试数据/`，
   **绝不重跑抓取**。（同理：任何 `_卷面生成工具/` 里出现 http/httpx 的脚本，先看清再跑。）
版式定版（第5课起）：
- **每模块独立一页**，题目卷目标=思维/专项/同步各恰好一页无空白页
  （spacer 分级 `sp/spm/sps/sp0` + 图右浮 + tight 行距压页；去页脚）；
- 节标题居中 17pt 蓝黑体，**不带一二三编号**；思维题模块 14pt/行高 2.0，其余 12pt；
- 小问（1）（2）（3）逐条换行；竖式必表格逐列对齐（`vs()`，禁字符 rjust）；带图题把图**拷到课次目录**嵌本地
  （🔴 相对路径，不许挂老区/OSS 绝对路径）；★ 难度星保留；
- **卷面无学生姓名、无内部词**（层/★分层名/素材/薄弱这类内部词一律不上学生卷）。

HTML → PDF（v2 口径用 Chrome，Edge 老路也可）：
```powershell
chrome --headless=new --disable-gpu --no-proxy-server --no-pdf-header-footer `
  --virtual-time-budget=20000 --user-data-dir=<临时profile> `
  --print-to-pdf="<out>.pdf" "file:///<绝对路径>/<out>.html"
```
🔴 三坑照抄别复验：**必用临时 profile**（撞正开着的浏览器会静默不写文件）；**写盘异步**
（转完 sleep 2 再读，否则拿到旧文件）；**目标 PDF 被打开会静默写不进**（换名 `.new.pdf` 再覆盖）。

### 4B. v2 渲染链路
```powershell
python 工具箱/组卷/paper_tool.py assemble --spec 组卷.json              # 建 artifact 壳+paper+item
python 工具箱/组卷/paper_tool.py render-pack --artifact <id> --out 备课/<…>/_源/render-pack.json
python 工具箱/渲染/render_paper.py 备课/<…>/_源/render-pack.json --out-dir 备课/<…> --stem 第N课 --png
```
测试卷用 `exam_paper` 骨架（卷头/满分/时长/评分表/密封线全旋钮）；同步练习册形态用
`工具箱/渲染/render_punch.py`（`sync_kaodian` 骨架，一考点组一槽位）。细节走「渲染出件」skill。

### 4C. QA 铁闸（两条路都要过）
**pymupdf/pdf2img 渲染逐页目检**后才算交付：页数对不对、分页归属对不对、图在不在、结构乱没乱、
**题目卷有没有泄答案/泄提示**。
```powershell
python 工具箱/渲染/pdf2img.py <出的PDF> --out-dir 备课/<…>/_源
```
然后 **人工 Read 那些 PNG 逐页看**——机器只管数得出来的，版面好不好看只有眼睛知道。
