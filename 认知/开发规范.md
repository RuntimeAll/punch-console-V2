# v2 开发规范（顶级正本 · 2026-08-19 起草）

> 🔴 **动因**（用户原话 2026-08-19）："我们的开发怎么感觉一点规范都没有，是否需要拉一份顶级的开发规范
> 下面统一一下，我感觉对未来的维护和拓展非常的不利"。
>
> **本文是什么**：v2 全体开发动作的顶级规范正本。它做三件事——
> ①**收拢**散落在 CLAUDE.md / `认知/` 各正本 / 各 PRD 卡 / 代码文件头里的既有纪律（**一条不改义，只归位并标出处**）；
> ②**补齐**工程层缺口（代码 / 测试 / 库访问 / 协作，标【新增】）；
> ③给每条规则配**能在本机真跑出一个数字**的检查方法。
>
> **本文不是什么**：不是大厂官僚制度。**写不出检查方法的规则不收**——那种规则等于没有。
>
> **三正本同级**（CLAUDE.md 顶部 2026-08-19 用户立）：[北极星](北极星.md)（为什么/往哪去）｜
> [数据结构](数据结构.md)+[架构总图](架构总图.md)（是什么）｜**本文**（怎么建）。
> 本文低于 CLAUDE.md 与 `认知/` 各 SSOT（优先级链见 G-4），高于代码注释与个人习惯。
