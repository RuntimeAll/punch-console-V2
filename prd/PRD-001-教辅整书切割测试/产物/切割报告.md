## 0. 结论段（贴回调度中心）

**v2 确定性切割器在教辅整书上成色可用，且比在试卷上更稳。** 拿四下人教《同步典例考点讲义》整书探版式、
按方言判定切了「第五单元 三角形·特性篇」一个单元（8 考点 / 39 题 / 29 图），**8 道守恒闸全绿，五个数全 100%**：
题目边界 39/39、归属预挂 39/39、例题↔练习配对 28/28、元信息抽离 56/56（账逐题平衡、REGEXP=0、误剥 0）、
导出还原 字符 3170/3170 + 图 29/29 + 逐题片段 39/39。需人审比例 **15.4%（6/39）**，全部集中在同一件事
（「其一。/问题二：」这类纯标签算标题还是算题面），人工复核 6/6 判对，**实际错误 0**。

**为什么教辅比试卷更好切**：试卷靠题号正则找边界（歧义大，1.5 会被剥成 5），教辅靠 `【典型例题N】`
`【对应练习N】` 这类**显式栏目标记**找边界，**无歧义**。老区"逐本书写方言正则"的痛苦不在于切不准，
而在于每本书要重探一次方言——这次证明：**探方言可以机器化**（有效性过滤 + 目录声明核对闸，
一条规则通吃本书三层重复目录，15 单元 / 149 考点与目录声明**逐单元全对**）。

**三个超出预期的发现**：
1. 🔴 **本书 0 个 OMML 公式**——算式全是纯文本。前两轮试卷上打磨的 OMML→LaTeX 链在本系列**整条不触发**，
   这一环的成色本轮**未被检验**（不是"通过"，是"没考"）。
2. 🔴 **答案版与原卷版结构同构**：`(标记类型, 编号)` 序列 **55/55 全等**，答案版题段数 **39 == 39** 切出题卡数。
   ⇒ 答案回填可**纯确定性按序列对位**，不需要文本相似度、不需要 LLM。这直接给"整个系列录入"省掉一大块。
   代价只有一条：答案标记有**两态**（`【答案】`31 处 + 裸 `解析：`8 处），只认前者会漏 20.5%。
3. 🔴 **老区三条已知坑在本系列不成立**，可以销账：页眉复制品污染、尾部水印黏最后一题、
   explain 概念配图不落库（本书方法点拨区 **0 张图**）。

**诚实的边界**：只切了 **1/15 个单元（39/645 题标记 = 6%）**；另外 14 个单元只过了结构核对闸，**没有真切**。
公式链、表格链、图选项题判定这三条在本单元**样本为 0**，未被检验。口径 J1（一个题标记算 1 道题还是按小问拆）
**待用户拍板**——按小问拆的话本单元是 46 题不是 39 题。

## 3. 教辅 vs 试卷：真差距在哪

| 维度 | 试卷（前两轮） | 本教辅整书 | 结论 |
|---|---|---|---|
| **边界锚** | 题号正则（`1.` `2.` …），歧义大 | **`【】` 栏目标记**，零歧义 | 🔴 教辅**更好切** |
| **层级** | 一级（大题→小题） | **四级**（单元→[部分]→考点→栏目） | 归属树是新增面，但结构规整 |
| **公式** | OMML 129 个，需 OMML→LaTeX | **OMML 0 个**，算式全纯文本 | 该链路**本轮未被检验** |
| **题号/分值** | 全卷连续题号 + `(3分)` | **无全局题号、无分值** | 元信息抽离面**变小**了 |
| **图** | 少 | 312 槽，**39% 是句中图** | 图保位是主风险，块流方案天然解决 |
| **并排** | tab 网格（选项） | **空白串并排**（计算题），148 行 | 需先 mask 作答空槽再判栏 |
| **答案** | 卷末"参考答案"分区 | **在另一个文件**（答案版 docx） | 跨文件，但**结构同构 55/55**，反而更好配 |
| **目录** | 无 | **三层重复目录** | 有效性过滤一条规则通吃 |

## 4. 哪类版式会切错（诚实清单）

### 4.1 本轮实际踩到并修好的（4 处）

| # | 现象 | 根因 | 修法 | 判据 |
|---|---|---|---|---|
| 1 | `用字母A、B、C分别表示三角形的3个顶点` 被判成**选择题** | 选项正则 `[A-D][．.、]` 不看前文 | 选项字母须**行首或前接空白**且首两字母升序 | G2（本卡新增） |
| 2 | 全书判出 **472 行**"并排"，实际只有 148 行 | `(        )` 作答空槽本身就是 8 个空格，被当栏分隔符 | **先 mask 空槽**再按 ≥4 空白切分 | H2（老区 §18 坑④原样复现） |
| 3 | 导出还原件里**方法点拨的 `1. 2. 3.` 编号全丢** | 讲解块也被做了小问号抽离 | 讲解块**不做**小问号抽离（那是行文层级不是题号） | E2 |
| 4 | 导出件 **`【方法点拨】` 打印两遍** | 栏目前缀只剥了典例/练习，没剥点拨 | 点拨标记同样剥进账本 | F2 |

> ⚠️ 第 3、4 条是**目检截图揪出来的，机器闸没报**——字符守恒闸只管"字在不在"，不管"编号有没有回到行首"。
> 这是本轮最有价值的一条教训：**守恒闸挡不住"顺序/位置"类缺陷，导出目检不可省**。

### 4.2 已知会切错 / 未被检验的（分类列明）

| 类别 | 说明 | 本单元样本 | 风险 |
|---|---|---|---|
| **图选项题** | 选项全是图、正文无 A/B/C/D 字母 ⇒ 会落到"填空"（老区 §6 坑⑧） | **0** | 未检验；第二单元观察物体（87 图）/第七单元图形的运动（66 图）必踩 |
| **表格题** | 全书 13 张表，本单元 **0 张** | **0** | 表格链（合并单元格/版式表分流）**未被检验** |
| **公式** | 全书 **0 个 OMML**；29 个 `.wmf` 分布在别的单元 | **0** | OMML→LaTeX 链**整条未触发**；wmf 公式图的处理**未检验** |
| **纯标签标题** | `其一。`/`问题二：边长的最值。` 判标题还是判题面 | 6（15.4%） | 已标中置信；人工复核 6/6 对，但**规则本质上是启发式**，别册可能出现"其一"开头的真题面 |
| **小图** | h<50px 的图全书 40 张（字符图/公式图/装饰图混在一起） | 本单元未细分 | 老区 §11/§14：31×31 小方块是 □ 字形该当文本、装饰图标该滤——**本卡未做细分**，先记数不自动丢 |
| **题面并排** | 一段里 2-4 栏并排的计算题 | 本单元 0（几何单元无递等式计算） | 第一/三/六单元密集，**未被检验**；会被切成 1 道题（老区口径：轻微欠切内容无损） |

### 4.3 源件本身的缺陷（不是切割器的锅，但要记）

- 答案版 `【对应练习2】` 的解析写成 `解析：8厘米7厘米、6厘米、5厘米、4厘米、100` —— 缺顿号 + 尾巴多个 `100`。
  录入时会原样带进库。**建议：答案回填加"尾随孤立数字"告警**。

### 5.2 目检对照（原件 PDF p82 ↔ 导出 p3）

**降级清单（4 项，都是已知选择不是 bug）**：

| 降级项 | 原因 | 要不要修 |

## 6. 分层建议（确定性层 / LLM 层 / 人审层）

> 这是给正式管线设计用的。原则：**能确定性做的绝不上 LLM**——本轮实证确定性层能吃下 100% 的结构工作。

### 6.1 确定性层（规则 + 闸，**本轮已实证可全自动**）

- 版式探测：标记清点、目录有效性过滤 + 剪枝、单元/考点数与目录声明核对；
- 结构切割：单元→[部分]→考点→栏目段，题目边界（39/39）；
- 归属树预挂考点名（39/39）；例题↔练习就近向上配对（28/28）；
- 元信息抽离带账（栏目前缀 / 小问号 / 标题 / 分值 / 来源）+ REGEXP=0 + 误剥闸（56/56）；
- 图/表/公式/可见字符多重集守恒闸；
- **答案版按 `(标记类型, 编号)` 序列对位回填**（55/55，本轮实证）；
- 题型判定（选择/判断/填空/解答）——**除图选项题外**；
- 导出还原成打印件。

### 6.2 LLM 层（确定性层做不了、且**值得**做的，本轮**只写建议不现场用**）

| 该干的事 | 为什么规则做不了 | 建议形态 |
|---|---|---|
| **图选项题的选项识别** | 选项是图、正文无字母，纯规则拿不到"这是 A/B/C/D 四个选项" | 视觉模型读图 → 输出选项数 + 各选项内容摘要；**只补 `question_type` 和选项结构，不改题面** |
| **纯标签标题 vs 真题面** 的兜底判定 | `其一。` 这类启发式在别册可能翻车 | 只对**低置信那 15%** 调 LLM 二判，高置信的不碰 |
| **考点↔知识图谱锚定** | `【考点五】三角形的高的画法` 挂到 KG 哪个节点，是语义匹配 | LLM 给候选 + 打分，**语义不符宁锚根**（老区 §10 铁律） |
| **难度标注 / 题型细分**（归一问题、鸡兔同笼变式…） | 纯语义 | 批量离线打标，不进切割主链 |
| **小图细分**（□ 字符图 / 公式图 / 装饰图标） | 40 张混在一起，尺寸判据不够 | 视觉模型逐张分类一次，结果落成 media 白名单**缓存复用**（全系列共用） |

### 6.3 人审层（**只审这些，别的别浪费人**）

1. **低置信项**（本单元 15.4%）——切割器已经把要审的挑出来了，逐条看；
2. **导出还原件目检**（🔴 **不可省**——本轮两条缺陷都是它揪出来的，机器闸没报）：每单元抽 1-2 页与原件 PDF 对照；
3. **每册首次录入时的方言复核**——单元数/考点数 vs 目录声明的核对闸虽然机器跑，但首册要人看一眼报表；
4. **源件缺陷判决**（如那条 `…4厘米、100` 的脏解析）——机器只能告警，改不改是人的事。
