# KG维护 —— 教材树与别名层原语（契约正本=认知/数据结构.md §2.2）

## 命令

```powershell
# 铺整枝（spec JSON → 版本/年级学期/单元/小节/叶+别名一次落，幂等可重跑）
python 工具箱/kg/kg_tool.py build-branch 工具箱/kg/首枝-浙教七上.json

# 挂单个考点叶（--id 省略=父 id + 3 位续号；--ord 省略=取 id 末三位）
python 工具箱/kg/kg_tool.py add-leaf --parent 100001002 --name 数轴上的动点问题

# 挂别名（alias_kind 记词源：老区名/老区细分点/产线词/教辅题型名）
python 工具箱/kg/kg_tool.py alias --kp 100002003003 --alias 倒数 --kind 老区名

# 产线词 → 现行叶子（名字精确 → 别名精确 → LIKE 兜底，打 id + 全路径 + 命中方式）
python 工具箱/kg/kg_tool.py resolve 倒数

# 并重复叶（引用全迁 + 源置退役 + 源名转别名）
python 工具箱/kg/kg_tool.py merge --from 100001003001 --into 100001003002

# 看树（⬜未铺 / ✖退役 / (别名N) 标记；带 id 只看该子树）
python 工具箱/kg/kg_tool.py show 100001
```

`--db` 缺省 = `<v2根>/知识库/kb.db`。退出码：0=成功，1=失败停手，**2=resolve 零命中**，**3=resolve 多命中待人选**。

## 纪律

- **沿老区 id 契约**：数字 id **每 3 位一层**——3 位=年级学期（老区册根）/6 位=单元/9 位=小节/12 位或 15 位=考点叶；
  存量老 id **原值保留不重编**（重编=老区全部引用一次性作废）。「版本」层是 v2 新加的顶层分组，
  id 用**非 3 倍长度的可读串**（`zjsx2024`），一眼区分于数字契约、绝不与老区 id 相撞。
- **名字干净**：编号进 `ord` 不进名字（「1.2 数轴」→ name=`数轴`、ord=2）；
  叶子=名词短语 **≥3 字**（add-leaf 硬闸：老区「比」一个词命中 87 个叶子，短名是 resolve 毒药）；
  教辅栏目（全章综合训练/重难专题/大招专题/项目化学习）**不占 KG 位**；同父同名由 DDL `UNIQUE(parent_id,name)` 兜。
- **别名是产线词翻译层**：老区名、老区细分点、教辅题型名、产线口语一律挂 `kp_alias`，
  `alias_kind` 记词源（后续要按词源回溯谁在用哪套叫法）；别名**只挂枝末端**（`assert_leaf_kp` 兜——
  考点细分出题型后，新别名该指题型节点）；别名与目标现名相同则跳过，不造自指别名。
  **改叫法 = 加别名，不是改 name**。
- 🔴 **题型层（2026-08-21 窗L，口径正本=认知/数据结构.md §2.2b）**：树是六层——考点之下可长
  **题型**子层（可选长，题量压得住才长，不预铺）。`add-leaf` 挂在考点下自动 level='题型'；
  **就近可挂**：考点长了题型后它自己不再收新挂载（挂载闸会列出该挂的题型）；存量旧挂载仍合法。
  批量铺题型走 `工具箱/kg/铺题型枝.py`（吃 题型锚定映射.json），别在这儿手挂一堆。
- **按需铺枝**：用到哪个专项铺哪枝；没铺的单元立 `status='未铺'` 占位，
  🔴 **绝不造空树凑完整**（空壳节点会被 resolve 命中，比没有更坏）。
- **resolve 多命中不自动挑**：打全部候选带全路径、退出码 3，交人工/调用方选；
  零命中退出码 2——**挂不上就别硬挂**，先 `add-leaf` 建叶或 `alias` 补翻译，绝不裸题入库。
- **merge 带引用迁移且同码两义拒并**：`question_kp` / `kp_alias` / 各表 `kp_ids_json`
  （question_pattern·solution_model·exam_model·error_cause·artifact）/ `err_code_map` / `cause_deposit` 全迁；
  **只并叶子**（源有子节点直接拒，整枝重组先人工拆）；错因码在目标已映射到**不同** cause_id → 中止交人工裁决；
  源节点不删，置 `退役` + note 记并入去向（血缘不断）。
- **同 id 两义绝不静默覆盖**：build-branch 撞到库内同 id 但不同名/不同父 → 如实报错停手，人工裁决。
- **库位**：worktree 里跑天然是沙盘副本；🔴 主位的 `知识库/kb.db` 只在主位动（SQLite 单写者）。
- 工具每次执行自动落 `skill_log`（skill='KG维护'），无需另记账。

## 铺新枝三步

1. **抽老区 dump**（老区只读，只产出到 v2）：
   ```powershell
   python 工具箱/kg/extract_oldtree.py <dump.sql> 100 工具箱/kg/参考/老区100树.json
   ```
   dump = `D:\workplace\ai-bkb\数据库清理-2026-08\备份\dev\_bak206_biz_subject.sql`（2026-08-05 快照）。
   🔴 dump 的 DDL 注释「1学科 2教材 3章 4节 5知识点」是**过期注释**，实际层义 =
   1 册根 / 2 章 / 3 节 / 4 知识点 / 5 细分点（考古正本：`认知/考古/KG命名体例-老区实况.md` §1.0）。
2. **人工整 spec**：照 `工具箱/kg/首枝-浙教七上.json` 的格式写——起干净名、定 ord、
   老名转 `aliases`、本期不做的单元标 `"status": "未铺"`；每条裁量（哪层不铺、哪个叶重铸、哪些栏目丢弃）写进报告。
3. **幂等铺**：`build-branch <spec.json>` → 打印「新建 / 已在跳过 / 状态更新 / 别名」四计数；
   重跑安全（跑两遍第二遍应全 skip）。铺完 `show <册根 id>` 目检层级与未铺占位。
