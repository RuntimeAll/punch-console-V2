# 举一反三 —— 认母题 → 深解析 → 算子调配 → 生成变体（流程正本=认知/业务流程.md §三）

## 🔴🔴 飞轮铁律（写死）

1. **变体必回流带血缘**：深度解析、母题、变体**全部入库**——母题先入（source_kind='manual'/'scan'，
   拿到 qid），变体 `mother_qid=<母题qid>` + `variant_op=<算子>` + prov；生成类 source_kind='model'，
   题库默认折叠（D-9：只有进入交付的实例才入库——草稿入、交付 promote）。
2. **模型必留档**：深解析产出「触发特征→动作结论」二元组 → `model_tool.py solution-add`
   （tier/freq 双旋钮）。🔴 模型必须存在——没模型就先蒸馏，否则变式必退化成瞎换数字（老区血案）。
3. **出题前必查库**：`model_tool.py coverage --kp <考点>` 看已有模型与题；
   有模型且只出「认/识/懂」→ 快线（跳蒸馏，但快线三闸一道不能少）。
4. **每写落 skill_log**（工具自动落账；里程碑 `log_skill.py 举一反三 …` 补总账）。

## 0. 开工前

`python 工具箱/库/inject_criteria.py 出题` 注入现行判据；
考点先 `kg_tool.py resolve` 通（不通先补 KG）；母题定位不确定（年级/章节存疑）→ 问用户，别硬猜。

## 1. 认母题（分流闸）

| 条件 | 路线 |
|---|---|
| 库有模型 + 只出 认/识/懂 | 🟢 快线：跳深解析，直接取模型调配 |
| 库有模型 + 要出 变一/变二 | 深线：可跳蒸馏，但必须吃透模型的「动作结论」骨架 |
| 无模型 | 🔴 深线全程，一步不能少 |

**快线三闸**（省了"解原题"就必须补）：①模型体检（抽 1 原题按模型卡实解走通，走不通退深线重蒸馏）
②错因靶子（各变体各瞄一个不同的坑：审题/概念/方法/计算/边界）③全量实算（快线深线都不能免）。

## 2. 深度解析

- 把母题**解对**：sympy/Fraction 独立重算，别信题面手写答案（老区实测过教辅答案错）。
- 蒸馏「触发特征（看到什么就用它）→ 动作结论（怎么做得到什么）」→ `solution-add` 入库。
- 母题此时入库（ingest_flow，题面血缘留 source_raw 出处）。

## 3. 算子/难度/场景调配（认识懂变·变一变二）

- **五级递进**：认=母题原型；识=数值同构（换数不换形，**句式与脚手架也照抄**）；
  懂=本质微调（结构不变但破表面定势）；变一=轻结构变式（加系数/移项/倒装）；
  变二=进一步迁移（表述外衣/叠加/更大跨度）。默认四题制（认/识/懂/变式训练），用户点名才五题。
- **难度走双旋钮**：查 solution_model.tier/freq **表驱动确定**，LLM 只匹配不自评；
  变式训练必须比前三题难（反转结构/存在性/含参反问/异系数），认识懂保持母题难度。
- 每个变体标注：算子名 + 变式系数（0-1 相似度）——落 variant_op 与解析卷。

## 4. 生成变体（全量实算过闸 + 血缘回流）

1. 🔴🔴 **答案绝对不准撞**：每个变体最终答案与母题答案/题目已知量/其它变体答案全不同
   （病根=只换算子壳不换数值；警惕问法塌缩——结构一变某量退化成恒等就换问法）。
2. 🔴 **题面表述闸**：主语写全禁「它」代指；「识」层照母题原句式同构；交付前把题面当学生通读一遍
   （纯语言闸，机器验算查不出来）。
3. 全量实算：逐题独立路径重算；交解析卷加跑 `工具箱/验算/逐行恒等校验.py`
   （中间行符号错、末行锚回正确答案的形态只有它抓得住）。
4. 回流：题目包 JSON（每题 mother_qid + variant_op + kp + prov + confidence）→
   `ingest_flow.py check` → `ingest` → 交付后 `promote`。
5. 出卷（如要 PDF）调「渲染出件」：题目卷/解析卷分双 PDF，解析卷逐题写算子+系数。

## 5. 交付标准（铁律）

- 双 PDF 独立成件；文件名=专项名（题目）/（解析）；黑白线条打印风。
- 每专项独立起页；页首=专项标题+方法串两件套（一页一个标题层级）；
  每题次标题=级名（1·认 / 2·识 / 3·懂 / 4·变式训练），专项内独立编号。
- 小问不拆（一标记一题）；产物落 `产物/举一反三/<专项名>/` 一目录装齐（题目/解析 PDF+生成源+总结.md）。
