## 1. 学情摸底（新学生第一节课的固定动作）

🔴 **"会算"≠"学会了"**。抢跑型孩子（幼小衔接就会 100 以内加减）普遍有三个隐藏坑，
第一节课用约 20 分钟验证，摸底结果决定整条课程路线：

| 验证项 | 怎么测 | 判什么 |
|---|---|---|
| **① 算理** | 让孩子用小棒/积木摆出"32−15 为什么要退位"，或口头讲给老师听 | 是真懂道理，还是背程序（"不够减就借一个"）？背程序的换情境就崩，三年级后优势消失 |
| **② 应用** | 3 道朴素应用题（"小明有 15 颗糖吃了 7 颗还剩几颗"级别），自己读题→找关系→列式 | 抢跑孩子应用题零基础是常态（好好即如此） |
| **③ 速度与稳定** | 口算限时一组（20 题/3 分钟级别） | "会但慢" vs "又快又稳"；好好当时=竖式会但口算慢 |

加测口头项：数的组成（"64 里有几个十几个一"）、比大小、简单找规律 —— 判思维底子。

**摸底产出**：一份学情单（会什么/短板/思维底子），据此定路线（§5）并**建档进 grading.db**（§6.1）。

## 2. 课堂结构（90 分钟标准模板 = 计划档头的「低龄七段」）

🔴 **两条硬规格**：单一活动不超过 **10 分钟**；纯讲授累计不超过 **30 分钟**。
一对一也不豁免——低龄孩子撑不住，撑不住的课=白上。

| 时段 | 环节 | 要点 |
|---|---|---|
| 0-10 | **口算热身** | 限时小竞赛，跟自己上次比（记录成绩形成曲线）；练速度与稳定性 |
| 10-30 | **新授①** | 一个知识点。🔴 顺序必须=**先动手摆（实物）→ 再画图 → 最后列式**（具象→图像→抽象），跳步=白讲 |
| 30-40 | **游戏缓冲** | 数学游戏消化新授内容，让孩子动一动（低龄课的呼吸口，不是浪费时间） |
| 40-60 | **应用题专练** | 核心时段。固定四步：**读出声 → 圈条件 → 画一画 → 列式**；每次只练一种数量关系 |
| 60-70 | **孩子当小老师** | 挑一道他会的题讲给老师听——能讲清才是真懂；一对一独有的黄金环节，不许省 |
| 70-85 | **思维题收尾** | 找规律/图形推理/简单奥数启蒙；思维好的孩子在这里喂饱 |
| 85-90 | **总结+作业** | 孩子口头复述今天学了什么；作业量少而准 |

60 分钟课=砍掉游戏缓冲、思维收尾减半；45 分钟课=只保留 热身/新授/应用 三段。

**题量口味（已拍板纪律）**：每组 **3 题刚好**，砍中间难度，尾题拔高；
专项卷走「认→识→懂→变式训练」四题制（详见「举一反三」skill）。

## 3. 低龄教学法六条（写进每份备课单的"教法"栏）

1. **实物先行**：小棒、积木、计数器、真硬币；不许上来就纸面符号。
2. **生活情境包装**：题目用孩子熟悉的东西（零食/玩具/家人）编；备课时就把情境写好，别指望课上现编。
3. **多感官切换**：讲、摆、画、说、玩轮着来，任何单一形式 ≤10 分钟。
4. **表扬努力不表扬聪明**："你刚才画图找到了关系，这个方法特别好"，不说"你真聪明"。
5. **错误当素材**：错了不批评，让孩子自己摆一遍找出哪步不对。
6. **让孩子讲题**：每课至少一次"小老师"环节（§2 表 60-70 段）。

## 4. 内容重心（一年级各版块怎么教）

| 版块 | 教学要点 |
|---|---|
| **计算** | 已会的只做限时保温（热身段），不整课刷；未懂算理的回炉用小棒重建（凑十法/破十法必须摆得出来） |
| **应用题** | 一年级最大增量。按数量关系分专项：合并求总→剩余→比多少→看图列式；每专项吃透再下一个 |
| **数感** | 数的组成、比大小、估一估、数序；穿插在热身与游戏段 |
| **场景应用** | 认钟表、认人民币——正式课标内容，也是最好的"用数学"素材（真硬币上手） |
| **思维启蒙** | 找规律、图形推理、简单逻辑（谁高谁矮）、火柴棒；每课收尾段固定供给 |

🔴 **不做的事**：不盲目赶一下/二年级进度（纯抢跑的领先到三年级消失，长期价值在数感和思维）；
不上整页计算题海；不教超越具象能力的抽象技巧（如一年级上乘法口诀速记）。

## 5. 课程路线模板（抢跑型学生，参照好好方针）

```
阶段一：一上查漏收尾        —— 重点=应用题+算理验证，计算只保温
阶段二：思维训练常态化      —— 每课固定思维段；可引入奥数启蒙教辅
阶段三：有余力再开一下+奥数 —— 一下按"具象→抽象"重走，不因为"提前学"就跳操作环节
```

每阶段推进以**孩子讲得清+用得出**为闸，不以"做对了"为闸。当前阶段填进计划档头的「现行阶段」。

`工具箱/dsl/有理数混合运算_qbank.py` 骨架新写一个（这是 LLM 在本产线唯一该出现的地方之一）。

### 6.5 自编题入库（老区「录题管线」六闸 → v2 `ingest_flow.py`）

```powershell
python 工具箱/kg/kg_tool.py resolve "<考点名>"                 # 🔴 resolve 不通先 add-leaf/alias，绝不裸题
python 工具箱/回流/ingest_flow.py check  题目包.json            # 干跑：块流闸+执行阀五条+叶子闸+等级审预判
python 工具箱/回流/ingest_flow.py ingest 题目包.json            # 真入库（草稿）🔴 先登记写窗口
python 工具箱/回流/ingest_flow.py promote --ids q…,q…           # 草稿→上架
```
题面 blocks 只放**题目本体**：题号/分值/「计算：」类指令词不进题面（版式的事，闸会拦）。

### 6.6 🔴 自编题七查（交付前必过）

逐题机器实算（题面直算/脚手架分步/巧法路径/解集唯一性/跨卷查重/范围闸）+ **逐行恒等校验**：
```powershell
python 工具箱/验算/逐行恒等校验.py <解析文件或题目包>
```
凡给了「＝」步骤链或分步框，**每一行都要与原式恒等**——只验最终答案挡不住「中间行符号错、
末行锚回正确答案」的解析错误。🔴 **低龄卷孩子照着错误步骤学会错方法，比答案错更坑**。
全套走「答案实算闸」skill。

### 6.7 备课纪律四条（已拍板，必守）

临上课必走本管线 + **全量逐字读上课内容**；备课单顶格明确**重点/难点**；
课次目录只留备课包成品、其余收 `其他/`；**不出答案卷/教师版 PDF**（低龄线口径，与四年级线不同）。

### 6.8 卷面纪律

学生可见卷面**绝不出现内部词**（层/★/基础过关·强化·拓展/素材/薄弱……），节标题只写干净知识点名；
上标只认 ²³，其余次方写"的 N 次方"（一年级基本用不到，防患）；卷面无学生姓名。

### 6.9 物料落位

备课产物统一进 `备课/<学生代号>-<批次名>/`，一课次一目录只放成品；
出变式卷走「举一反三」skill；成品挂账走「资料挂账」skill：
```powershell
python 工具箱/挂账/artifact_tool.py add --name "好好·第7课·比多比少与求相差（专项卷）" --kind 专项卷 `
  --file 备课/<…>/①思维题.pdf --file 备课/<…>/②同步.pdf --kp <考点> --source-line 一年级备课
```
