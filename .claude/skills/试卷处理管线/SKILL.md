# 试卷处理管线 —— 轻结构化（OCR/文字层 → 格式件）

## 定位（2026-08-20 用户口径）

> "不需要非常复杂，只需要用 OCR 将试卷格式化就可以了，方便下面的处理完成后接力完成。"

本 skill 只做**纸→结构化格式件**这一段，产物是文件不是库记录。两个接力口：
- 🔴 **接力①吃入库（2026-08-20 定版，PRD-008 §一②-4）**：不再手搓 ingest 包，走确定性转换器——

  ```
  结构化.json ──工具箱/回流/pack_builder.py build──▶ ingest 包 ──ingest_flow ingest──▶ kb.db
  ```

  `pack_builder` 零 LLM、字节级可复算，负责：顶层键归一 / qtype·难度翻库口径 /
  考点名走 kg resolve 挂叶（挂不上进低置信清单**不硬挂**）/ prov 组键（八键+版本四键）/
  figure 块注入（吃 `--figure-manifest`）/ **守恒闸**（输入 = 进包 + 滞留，不平拒转）。
  含图题没给 manifest ⇒ **整题滞留不产半残包**；图先走 `ingest_flow asset-add` 落位登记。
  无答案态合法（answer_blocks 省略）；🔴 主位库写动作到 记录/开发注册.md 登记写窗口。
- **接力②平行出卷**：按讲义考点（kp.desc 已带考法清单）走 举一反三/dsl_batch 出平行测试卷。

## 步骤（一份卷一遍）

1. **落档**：原件拷入 `测试数据/试卷/<卷名>/`（微信目录易失，先拷）；
2. **体检**：python fitz 逐页——有文字层走文字层+页面图核对；纯扫描件才 OCR（渲 300dpi PNG 逐页视觉转写）；
   报数：页数/平均字符/稀薄页/get_drawings 计数；
3. **锚点切题**：大题节（一、选择题…）+ 题号（行首 `\d+.`）双锚切割；🔴 题号可能节内重置，
   不许按单调递增判边界；跨页题按题号缝合不按页断；
4. **公式核对**：🔴 文字层的数学不可信——分数拆上下行、括号/绝对值竖线矢量化丢失、上下标降格、
   循环小数点消失。公式密集题必须渲页面图（dpi≥150）对照转写 $LaTeX$，没把握标 `低置信:true`；
5. **选择题**：选项用 option 块契约 `{"type":"option","label":"A","blocks":[{"type":"text","role":"题面","md":…}]}`
   ——入闸（标号连续闸）/页面/渲染出件（choice 槽）三端已实测兼容（render_paper_test 40 绿）；
6. **图题**：看图才能做的题不硬转，标 `图题:true` 记页码区域（get_images 常为 0，矢量图用
   get_drawings 计数>40 嗅探）；要求学生自己画图而题面无图的照常转；
   🔴 **图与题分两步走**：本 skill 只留证（`图` 字段记页/区域/描述），**不搬二进制**；
   图的落位登记归 `ingest_flow asset-add`，题里的 figure 块由 `pack_builder --figure-manifest`
   注入。凡 `图题:true` 或 `图` 非空的题，manifest 没给条目就**整题滞留**——半残题不入库；
7. **净化**：剥水印/广告行（黑名单先扫全卷高频行）、剥裸指令词前缀（"计算："），保留带信息的方法提示；
   小问 (1)(2)(3) 不拆——一题一标记；
8. **守恒+目检**：`扫到 = 结构化 + 图题 + 存疑` 三堆必须对上并写进 目检.md；抽 3 题贴页面截图
   与结构化结果对照。

## 结构化.json 标准态（本 skill 的交付契约，🔴 2026-08-20 定版）

> 立此版之前卷7/卷8 两派顶层键并存（卷目录 vs 卷、卷头 vs 卷面、页文件字典 vs 数组），
> 接力段每次都得现认结构。**下表即唯一标准态，新件一律照此产**；转换器对旧件的兼容读
> 只是过渡，不是第二口径（字段单名制，同物两名=静默丢的坑）。

```json
{"卷名":"第2章 有理数的运算单元测试卷（B卷提升篇）【浙教版】",
 "卷":"卷8",                                  ← 卷目录名（旧键「卷目录」已废）
 "来源":"测试数据/七上试卷/卷8",                 ← 🔴 全相对 v2 根
 "source_kind":"scan", "页数":5,
 "页文件":[{"页":1,"文件":"xx.jpg","相对路径":"测试数据/七上试卷/卷8/xx.jpg"}],  ← 数组态（旧字典态已废）
 "卷面":{"标题":"…","满分":120,"考试时间分钟":100,"教材版本":"浙教版","范围":"…","卷型":"…"},  ← 旧键「卷头」已废
 "大题":[{"节":"一、选择题","题号":["1","2"],"每题分值":3,"节分值":30}],       ← 可选
 "配方":{…},                                                              ← 可选
 "题目":[{"题号":"1","大题":"一、选择题","页":2,"qtype":"选择题",
   "blocks":{"v":2,"rows":[{"cells":[{"type":"text","role":"题面","md":"…"}]}]},
   "图题":false,"图":[{"页":2,"页文件":"…","区域":[l,t,r,b],"描述":"…","读图必需":true}],
   "低置信":false,"低置信原因":"","备注":"",
   "难度建议":"中档","考点建议":["相反数"],"考点置信":"高",
   "prov":{"来源":"…","卷":"卷8","题号":"1","页":1,"卷名":"…","大题":"…","卷面分值":3,
           "页文件":"测试数据/七上试卷/卷8/xx.jpg"}}],                        ← 🔴 prov 固定八键，页文件写相对路径
 "守恒":{"扫到":N,"结构化":N,"图题":N,"存疑":N}}
```

🔴 **rows 必须带 cells 包层**（PRD-008 §一②-4 契约修正，2026-08-20 立）：块流是
**`rows[].cells[]` 两层**——`rows` 的每个元素是 `{"cells":[…块…]}`，**不许把块直接摊在 rows 里**
（`rows:[{"type":"text",…}]` 是错的）。行=版面上的一横排（选项四块同排就是一行四 cell），
丢了这层，选项排布与图文同排关系就整个塌掉；`gates.validate_blocks` 与 `pack_builder` 两端都拦，
出包时报「rows[i] 缺 cells 包层」并**整题滞留**。

**逐题字段口径**：`难度建议`∈送分/巩固/中档/压轴、`qtype`∈选择题/填空题/解答题/应用题/计算题/
判断题/作图题/证明题/实验探究题（值域=库 `dict_item`，翻不出的转换器拒收不猜）；
`考点建议` 写产线词即可（转换器 resolve 到叶，挂不上不硬挂）；`考点置信`∈高/中/低。

## 版式坑清单（2026-08-19 讲义快录 11 组实测，接力必读）

水印五行插在题干与选项之间（先黑名单过滤再切题）｜分数=上下两行拍平｜带分数拆三段｜
`(-2)²` 与 `-2²` 文字层无法区分（必看图）｜方括号/大括号/绝对值竖线整个蒸发｜
数轴/几何标号文字层顺序是错的（一律看图）｜表格被拍平成逐格独立行（用 page.find_tables 或转 GFM）｜
选项排布一行四列/两行两列/竖排四行都有（按视觉阅读序不按 x 坐标序）｜页眉页脚与书页码≠PDF 页号。

## 纪律

- 🔴 只写 `测试数据/试卷/<卷名>/` 与自己的临时目录；主位 知识库/ 两库一个字节不碰；
- 🔴 **交件即交接**：结构化件出完，接力段照 §接力① 三条命令跑（`pack_builder manifest` 出图骨架 →
  `asset-add` 落图 → `pack_builder build` 出包 → `ingest_flow check/ingest`），**不许现搓转换脚本**；
- py 头 utf-8 reconfigure；文件指针全相对路径；每次执行落 skill_log（接力①入库时由 ingest_flow 自动落）；
- 转写没把握=标低置信不硬猜；扔题必留名（守恒三堆）；
- 并行处理多份卷：一份卷一个子目录互不相扰；批量>3 份先给用户报一份样张过目再放量。
