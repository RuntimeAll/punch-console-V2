## 0. 铁律速查（写之前读，写完再读一遍）

**四不写**

| ❌ | 原因 |
|---|---|
| AI / 智能生成 / 自动出题 / 大模型 | 暴露产线；"AI 出的题"在家长眼里 = 不可信 |
| 每题程序验算过 / 机器复核 / 零错误 | 对外**默认就该是对的**；把内部质检当卖点讲＝暗示同行不验、我们出过错 |
| 层级词：基础层 / 强化层 / 拓展层 / 第几层 | 内部编排语言，不进客户视野 |
| 空形容词：精心打磨 / 干货满满 / 强烈推荐 | 占字数不给信息 |

**四必写 = 🔴 买家四问**（2026-08-04 用户点名：**「只关心，我们是什么教材，是不是最新，涉及的范围，作用是什么」**）

| ✅ 家长问什么 | 答什么 / 落到哪 |
|---|---|
| ① **什么教材** | 版本 + 年级 + 册（人教版七年级上册…）。**标题里就要有年级词**；见 §0.1 |
| ② **是不是最新** | 🆕 **2026 年新版教材**——标题里点「新教材」，正文写「按 2026 年新版人教教材编排」。<br>🔴 **标不了就换真话说**：把**章序列出来**让家长自己对课本目录，别硬标年份 |
| ③ **涉及范围** | **具体章名 + 具体知识点名**（绝对值 / 去括号 / 合并同类项…）。<br>❌ 别写「八大板块」这种**我们的内部切法** |
| ④ **作用是什么** | 拿来干嘛（开学同步 / 期中期末突击 / 假期补）+ **治什么毛病**（具体错法） |

🔴 **量与页数是佐证，不是主角**：`N天M题 / 双卷页数 / 交付形式` 一个都不能少，
但**降到「规格」那一行**，**不进标题、不当开头**。
**没有家长因为"题多"下单，只因为"对得上、管用"下单。**
（**我们的特点**§0.2 五选二三，落正文中段。）

🔴 **「新教材」比「最新人教版」值钱得多**（2026-08-04 用户点名）：
家长买教辅最怕买到旧版对不上课本，**写年份是直接消掉这个顾虑**，
比含糊的「最新」有力，也比任何形容词都实。**标题里就要出现。**
⚠️ 但**必须真的是新版教材编排的**才写——写了对不上，退货和差评都跑不掉。

**长度**：小红书正文 **≤12 行**（口径：**不含空行与 `#标签` 行**，一屏读完），标题 🔴 **≤15 字**（2026-08-05 用户收紧）。
能删的形容词全删；超了就压路线（可两天一组合并）。

**主武器**：🔴 **把 N 天路线直接列出来**（Day1 练什么 → DayN 练什么）。
一眼看出不是随机凑题，比任何形容词都有说服力。**凡能列的册子必须列。**
⚠️ 但路线行里写的必须是**课本上的知识点名**，不是我们的内部叫法
（❌「绝对值压轴突破」→ ✅「绝对值化简与最值」；❌「混合长链」→ ✅「实数混合运算」）
——路线既是「涉及范围」，也是正文里最密的一片搜索词，见 §0.05。

### 🆕🔴 0.05 搜索词：标题是**搜索入口**，不是广告语（2026-08-04 用户点名）

> 用户原话：**「描述要好搜索，适配搜索的内容，你现在太小众了，可能都不会被搜索到」**。

**病根 = 标题写自造词**（「计算一本通」「八大板块」「1037 题」「压轴突破」）
——**没有一个家长会把这些打进搜索框**。笔记再好，搜不到就等于没发。

**动笔前先填这张词矩阵**（A/B 两版各吃一个**不同的**知识点词族，别抢词）：

| 层 | 举例 | A 版 | B 版 |
|---|---|---|---|
| ① **年级词**（必带一个） | 初一数学 / 七年级上册数学 / 五年级下册数学 | | |
| ② **知识点词**（最值钱） | 有理数 / 绝对值 / 整式加减 / 合并同类项 / 化简求值 / 分数加减 | | |
| ③ **题型需求词** | 计算题 / 计算专项 / 每日一练 / 练习册 | | |
| ④ **场景词**（有时效） | 开学预习 / 暑假预习 / 期中复习 / 期末复习 | | |
| ⑤ **形式词** | 电子版 / 可打印 / 打印版 / PDF | | |

**标题 = ①+② 硬拼**（🔴 ≤15 字，塞得下再加 ③④⑤ 其一）。
**标签 8~10 个分层挂**：大词 + 精准知识点词 + 场景词 + 形式词
——只挂 `#浙教版` 这类窄词 = 自断流量。
🔴 **教材版本窄（浙教/北师大）时，正文单开一行说明别的版本能用哪几段**：
既吃到人教的搜索流量，又不撒谎（样例：`七上计算合刊/_交付/发布物料.md`）。

### 0.1 教材归属自检（错标比不标伤更大）

现行人教版初中数学（2024 秋新教材）**七上只有六章**：
①有理数 ②有理数的运算 ③代数式 ④整式的加减 ⑤一元一次方程 ⑥几何图形初步。
🔴 **实数（平方根）在七年级下册第八章，不在七上。**

- 能对上人教章节 → 写「人教版 X 年级 X 册 第 N 章《XX》」
- 只能对上浙教/北师 → 写「人教版 X 下第 N 章 / 浙教版 X 上第 N 章」，
  **把跨版本说成"预习正合适"，反而多一个卖点**
- 跨两册（如表内乘除法＝二上乘法＋二下除法）→ 只写知识点名，**别写"X 上同步"**

全表 = `举一反三产物/打卡/发布物料正本.md` §2。**新册上表前先在那里加一行。**

### 0.2 我们的特点（五条，挑 2~3 条讲）

1. **一天一页，撕下来就能用** —— 排好班的册子，不是散题合集。
2. **题目卷、答案卷分成两册** —— 学生手上那本不带答案，抄不了。
3. **答案是完整过程，不是只给得数** —— 错了能定位到第几步，不用家长重讲。
4. **题目下方留白按题量分配** —— 直接在卷面写步骤，不用草稿纸，过程留在纸上。
5. **N 天路线是设计过的，每天攻一个具体的坑** —— 即主武器，直接列路线。

## 3. 🔴 A/B 两套 = 两个小红书账号（一号一版，绑定后不换）

**每册必出 A/B 两套物料**——不是"备用"，是**两个号各用一套**（2026-08-03 用户口径）：

| | **A 版** → `{{账号A}}` | **B 版** → `{{账号B}}` |
|---|---|---|
| 号的特点 | 🔴 老号 **1500+ 粉**，有存量流量，发新册优先它 | 新起的号，养号期，同册错开时间再发 |
| 🔴 **正文骨架** | `LAYOUT='{{骨架甲}}'` | 🔴 **`LAYOUT='{{骨架乙}}'`（必须是另一套骨架）** |
| 🔴 **封面/目录版式**<br>（有前页的册子才填） | `{{前页版式甲}}` | 🔴 **`{{前页版式乙}}`（必须是另一套）** |
| 🔴 **配图取哪几条线** | `{{甲组线}}` | 🔴 **`{{乙组线}}`（与甲**零重叠**）** |
| 🔴 **文案侧重** | **准确性** | **实时性** |
| 标题吃哪层词 | ② 知识点词 | ④ 场景词 |
| 水印（只防盗图） | `#7a7a7a` / opacity .7 | `#2b2b2b` / opacity 1.0 |
| 数据源 | ← **同一份，题一道不改** → | |

🔴🔴 **两版必须走不同的版面骨架**（2026-08-05 用户拍板：「AB版需要走不同的模版了，
就算是水印也不顶用」）。~~旧口径「只改水印深浅 + dpi 错开」~~ **已废**：
平台判重看的是**版面结构**，水印只是页脚几十个像素、dpi 只是缩放，**都改不动结构**。
骨架要差在题号形状 / 栏数 / 节头形式 / 留白位置 / 分隔手段上——详见 skill §4②。

🔴🔴 **隔离不止正文骨架**（2026-08-10 补，用户：「两个AB线相互隔离，两者不互通，
内容同源但页面排版和结构不同」）：**封面/目录版式**、**配图取哪几条线**同样要两套。
七上第二单元合刊本踩过——正文分了骨架，前页两版共用一份 CSS，
于是双号发出去的**头两张图是同一张脸**。

🔴 **填完这张表就跑机器闸**（别靠人记七条）：
```powershell
python .claude\skills\每日打卡\templates\AB隔离闸.py <册目录>
```
它逐页比两版的**几何指纹**（span 的 x/y/字号，不含文字），撞了就报；配图另查字节重复与取线重叠。

🔴 **文案侧重也分工**（2026-08-05）：**高粉号重准确性**（教材版本、章序、知识点写死写准，
不赶时间不蹭热点——错一次伤的是攒了很久的信任）；**低粉号重实时性**（蹭开学/期中/月考
时间节点，标题带时间锚，宁可快——没有存量，试错成本低）。

🔴 **一号一版，绑定后不换**：同一个号一直发同一套骨架。混着发＝两个号的图互相判重，
两套骨架就白做了。**每套物料齐两件**：那一版的 PNG（{{天数}} 张题目页）+ 那一版的文案。

🔴🔴 **网盘链接一册只建一条，两个号共用**（2026-08-04 用户口径：「不要做两个，只需要一个就够了」）。
~~原先 A/B 各建一条~~ 已废——网盘 PDF **无水印**，两条链接内容一模一样，
多一条只是多一份维护（改版传两处、总表多一行、发错号还要回查）。**要分的是图和文案，不是链接。**

🔴 **两个号的文案不能一样**——小红书判重复内容/搬运，轻则不推荐重则限流。
同册第二个号发的时候，标题与正文**重写**（卖点、题型清单、适用人群可复用作底稿）。

### 怎么出这两套

🔴 **换 `LAYOUT`，不是换水印**——**数据源统一（题一道不改），两个骨架各出一次**：

```python
for tag, layout in [('A', '{{骨架甲}}'), ('B', '{{骨架乙}}')]:
    render_book(layout=layout, days=DAYS, ...)      # ← 同一份 days，换骨架
```

⚠️ 两套骨架**各自的页数可以不同**（版面变了分页自然变），但各自内部仍要守
「**题目卷页数 = 天数**」那条闸——出完**两套都要断言**，别只验 A。
🔴 **绝不为了差异化改内容**：改了 = 两个号的答案对不上，客户拿到两版会以为买错。
脚本样板 = `打卡/七上计算合刊/_源/gen_xhs_variants.py`（复用同一份数据重渲、页数断言不变），
把其中「换水印」那一步扩成「换 LAYOUT」。
