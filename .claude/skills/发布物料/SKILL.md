# 发布物料 —— 三件套 + AB 隔离闸（v2 版）

## 0. 口径正本

**`记录/发布物料正本.md`**：§0 文案口径（四不写/四必写/标题词层/长度）——照它写；
各册文案定稿登记进它的 §3（文案改正本、别改分册副本——两份文案=两处漂移）。
每次出料 `log_skill.py 发布物料 <册名> …` 落账。

## 1. 三件套

| 件 | 用途 | 要点 |
|---|---|---|
| 小红书文案 | 发笔记 | 标题 3 选 1（≤20 字，年级词+知识点词+题型需求词硬拼，自造词没人搜）+ 正文 ≤12 行（主武器=Day1→DayN 路线直接列出来，写课本知识点名）+ 标签 8~10 分层挂 + 配图顺序 |
| 图片物料 | 笔记配图 | 第 1 张必须合成封面（别拿 A4 卷子页当封面）；正文取三条不同的线各第 1 天；A/B 两套骨架各出一份（走「渲染出件」，PNG 带水印：A 浅 #7a7a7a / B 深 #2b2b2b） |
| 商品上架描述 | 挂店/朋友圈 | 一整段连贯的话（200 字上下），不做表格：是什么→给谁→多少量→什么形式怎么拿→怎么用→一句卖点；量/页数/永久网盘链接等硬信息一个不少 |

**AB 文案侧重**：A 号（高粉）重准确性吃知识点词层；B 号（养号）重实时性吃场景词层——两号不抢同一个词。

## 2. 🔴 AB 隔离七维 + 机器闸

正文骨架 / 封面+目录版式 / 配图取线 / 文案骨架 / emoji 集 / 数字写法 / 标题词层——七条全隔离；
**必须相同**：题与答案、题序、网盘链接（一册一条双号共用）、教材归属与规格数字的事实。

```powershell
python .claude\skills\发布物料\scripts\AB隔离闸.py <册目录>     # 逐页几何指纹必须不同；发前全绿
python .claude\skills\发布物料\scripts\文案查重.py <新文案.md>  # 对 记录/发布物料正本.md 查同质化
```

## 3. 宣发字段落账（本 skill 的出口）

三件套定稿 → 写成 JSON（标题候选/正文/标签/商品描述/配图清单）→
`python 工具箱/挂账/artifact_tool.py note --id <A…> --json <宣发字段.json>`——
artifact 一本账里这册资料从此带着自己的宣发物料。

## 4. 交给用户怎么发（agent 到此为止）

1. 传图按文件名顺序，合成封面是首图；2. 文案复制粘贴，🔴 话题在 App 里逐个从下拉选（粘正文不生效）；
3. 网盘分享语在文案末尾现成三行。⚠️ 两个号错开时间发。
🔴🔴 发布动作永远用户手机 App 人工发。
