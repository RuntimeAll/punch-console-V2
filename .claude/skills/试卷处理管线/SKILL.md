# 试卷处理管线 —— 轻结构化（OCR/文字层 → 格式件）

## 定位（2026-08-20 用户口径）

> "不需要非常复杂，只需要用 OCR 将试卷格式化就可以了，方便下面的处理完成后接力完成。"

本 skill 只做**纸→结构化格式件**这一段，产物是文件不是库记录。两个接力口：
- **接力①吃入库**：格式件 → ingest 包（格式=工具箱/回流/ingest_flow.py 的 pack 契约，
  样例=试验场/2026-08-19-讲义快录/packs/）→ `ingest_flow ingest --partial` 过三闸入 kb.db。
  无答案态合法（answer_blocks 省略）；🔴 主位库写动作到 记录/开发注册.md 登记写窗口。
- **接力②平行出卷**：按讲义考点（kp.desc 已带考法清单）走 举一反三/dsl_batch 出平行测试卷。

## 步骤（一份卷一遍）

1. **落档**：原件拷入 `测试数据/试卷/<卷名>/`（微信目录易失，先拷）；
2. **体检**：python fitz 逐页——有文字层走文字层+页面图核对；纯扫描件才 OCR（渲 300dpi PNG 逐页视觉转写）；
   报数：页数/平均字符/稀薄页/get_drawings 计数；
3. **锚点切题**：大题节（一、选择题…）+ 题号（行首 `\d+.`）双锚切割；🔴 题号可能节内重置，
   不许按单调递增判边界；跨页题按题号缝合不按页断；
4. **公式核对**：🔴 文字层的数学不可信——分数拆上下行、括号/绝对值竖线矢量化丢失、上下标降格、
   循环小数点消失。公式密集题必须渲页面图（dpi≥150）对照转写 $LaTeX$，没把握标 `低置信:true`；
5. **选择题**：选项用 option 块契约 `{"type":"option","label":"A","blocks":[{"type":"text","role":"题面","md":…}]}`
   ——入闸（标号连续闸）/页面/渲染出件（choice 槽）三端已实测兼容（render_paper_test 40 绿）；
6. **图题**：看图才能做的题不硬转，标 `图题:true` 记页码区域（get_images 常为 0，矢量图用
   get_drawings 计数>40 嗅探）；要求学生自己画图而题面无图的照常转；
7. **净化**：剥水印/广告行（黑名单先扫全卷高频行）、剥裸指令词前缀（"计算："），保留带信息的方法提示；
   小问 (1)(2)(3) 不拆——一题一标记；
8. **守恒+目检**：`扫到 = 结构化 + 图题 + 存疑` 三堆必须对上并写进 目检.md；抽 3 题贴页面截图
   与结构化结果对照。

## 结构化.json 格式（本 skill 的交付契约）

```json
{"卷名":"…","来源":"<原件相对路径>","页数":N,
 "题目":[{"题号":"1","大题":"一、选择题","页":2,
   "blocks":{"v":2,"rows":[…]},        ← 直接用 blocks v2（省一次接力转换）
   "qtype":"选择题","图题":false,"低置信":false,"备注":""}],
 "守恒":{"扫到":N,"结构化":N,"图题":N,"存疑":N}}
```

## 版式坑清单（2026-08-19 讲义快录 11 组实测，接力必读）

水印五行插在题干与选项之间（先黑名单过滤再切题）｜分数=上下两行拍平｜带分数拆三段｜
`(-2)²` 与 `-2²` 文字层无法区分（必看图）｜方括号/大括号/绝对值竖线整个蒸发｜
数轴/几何标号文字层顺序是错的（一律看图）｜表格被拍平成逐格独立行（用 page.find_tables 或转 GFM）｜
选项排布一行四列/两行两列/竖排四行都有（按视觉阅读序不按 x 坐标序）｜页眉页脚与书页码≠PDF 页号。

## 纪律

- 🔴 只写 `测试数据/试卷/<卷名>/` 与自己的临时目录；主位 知识库/ 两库一个字节不碰；
- py 头 utf-8 reconfigure；文件指针全相对路径；每次执行落 skill_log（接力①入库时由 ingest_flow 自动落）；
- 转写没把握=标低置信不硬猜；扔题必留名（守恒三堆）；
- 并行处理多份卷：一份卷一个子目录互不相扰；批量>3 份先给用户报一份样张过目再放量。
