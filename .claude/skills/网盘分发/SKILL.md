## 1. 双通路架构（别自己另起通路）

| 动作 | 通路 | 说明 |
|---|---|---|
| 上传/列目录/读盘 | 官方 REST API（panctl.py） | token 在 password/baidu-pan.env，30 天期，`auth refresh` 续 |
| 建分享链接 | 持久浏览器页面内 fetch（panbrowser.py） | 官方分享接口被资质卡死；profile 在 password/baidu-pan-profile（已平移，别删） |

## 2. 常用命令（PowerShell 跑；🔴 `/apps/...` 路径别在 Git Bash 跑，MSYS 会改写路径）

```powershell
$P = "D:\workplace\ai-bkb-v2\.claude\skills\网盘分发\scripts\panctl.py"
python $P auth status                          # 先跑：token 有效期 + 登录态
python $P ls                                   # 应用目录已有什么
python $P upload <干净目录> "<年级>/<册名>" --ext pdf        # 传（改过版必加 --force）
python $P share "/apps/文档自动上传同步/<年级>/<册名>" --period 0   # 对目录建一条链
python .claude\skills\网盘分发\scripts\panbrowser.py status   # 登录态失效才让用户扫码
```

## 3. 🔴 三个必踩坑（老区实伤，照抄）

1. **改版重传不加 `--force` = 发旧货**：幂等判据是「同名+同大小」不看内容；改版后体积没变会打
   `跳过(已存在同大小)` 且末尾照样 `PASS`。**只要本地内容变过一律 `--force`，传完 `ls` 验 fs_id
   变了才算数**（覆盖文件不换分享链接——分享的是目录）。
2. **上传前先集结干净目录**：`_源/` 下常躺中间产物与废版 PDF，`--ext pdf` 拦不住废版；
   传前验页数+正文无水印（封面品牌署名要留）。
3. **一册一条链接**：题目卷+答案卷装同一网盘目录，对**目录** share 一次；双号共用这一条
   （双号分开的是配图水印与文案，不是链接）。链接必须自带 `?pwd=`（share 已自动拼）。

## 4. 风控纪律

日上限 300 条分享；share 默认 3 秒间隔+抖动，不要调 0 不要并发；
永久封号红线=分享内容违规——**别拿这通道传来源不明的教辅 PDF**（自编资料不沾）。
